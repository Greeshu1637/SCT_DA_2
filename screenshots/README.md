# Screenshots Guide

This folder should contain screenshots demonstrating the data cleaning process.

## Recommended Screenshots

### 1. **cleaning_output.png**
- Capture the terminal output when running `python src/clean_data.py`
- Shows the entire cleaning pipeline in action
- Demonstrates each cleaning step with statistics

### 2. **before_after_comparison.png**
- Compare the original vs cleaned dataset
- Show missing values, duplicates, data types before and after
- Can be captured from Jupyter notebook

### 3. **cleaned_data_preview.png**
- Show the first few rows of the cleaned dataset
- Display the standardized column names
- Show the final shape and data types

### 4. **outlier_visualization.png** (Optional)
- Box plots showing outlier detection
- IQR analysis visualizations
- Can be generated from the Jupyter notebook

### 5. **jupyter_notebook.png** (Optional)
- Screenshot of the Jupyter notebook interface
- Shows the interactive data cleaning process
- Demonstrates code with explanations

## How to Capture Screenshots

1. **For Terminal Output**:
   - Run `python src/clean_data.py`
   - Take a screenshot of the complete output
   - Save as `cleaning_output.png`

2. **For Jupyter Notebook**:
   - Open `notebooks/Data_Cleaning.ipynb`

   - Run all cells
   - Take screenshots of interesting sections
   - Save with descriptive names

3. **For Data Comparison**:
   - Open the cleaned CSV in Excel or VS Code
   - Show the clean, standardized structure
   - Save as `cleaned_data_preview.png`

## Tips for Good Screenshots

- Use high resolution (at least 1920x1080)
- Ensure text is readable
- Crop unnecessary whitespace
- Use descriptive filenames
- Include terminal/notebook headers for context
